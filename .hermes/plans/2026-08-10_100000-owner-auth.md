# Owner Auth (alone) — Implementation Plan

> **For Hermes:** implement with TDD; commit; push.

**Goal:** add owner authentication to the Casting HTTP API — scoped to auth ONLY
(no multi-project workspaces; we save those for later). Opt-in so existing
tests / local runs are unchanged.

## Model

- `AppState` gains `auth_token: Option<String>` (the owner's secret bearer
  token). `None` = auth disabled (backward compatible). Enabled via
  `AppState::with_owner_auth(token)`.
- main.rs reads `CAST_OWNER_TOKEN` env; if set, enables auth.
- `POST /api/login {token}` → 200 `{ok:true}` if it matches the configured
  token, else 401. Lets a UI verify/enter the token once.
- A tower middleware guard on the **owner-mutating** endpoints (message,
  decision, policy, directive, hire): require `Authorization: Bearer <token>`
  when auth is enabled; otherwise 401. Read endpoints stay open (the owner
  already gates the whole site behind Caddy basic auth in production; this is
  the write-authority boundary inside the app).
