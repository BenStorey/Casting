# Casting — Architecture Review (2026-08-13)

Full review of the event-sourced Rust/React core + harness periphery, prompted by
Ben after the harness-guards work (budget breaker, secrets, watchdog).

## Verdict

- **The event-sourced core is coherent and consistent** — the moat holds.
- **All conflicts/duplication sit at the harness/side-effect periphery**, and
  they share one root cause: **the durable executor was built but never wired
  into the live loop.**

## Findings (prioritized)

### HIGH — The durable executor is disconnected; two parallel side-effect mechanisms
`src/executor.rs` documents itself as *"the ONLY place real external work
happens."* But the only real side effects (worktree provision, git commit,
worktree prune) run **inline** in `pm::run_planned` via
`ws.provision_worktree`/`ws.commit_in_worktree`/`reconciler::prune_worktrees` —
a hardcoded `if event.event_type == …` if-ladder bolted onto the action→event
loop. There are **0 non-test call sites** of `executor::execute`/`schedule`
(only crash-recovery `redispatch_inflight` in main.rs + tests).

Consequence: the guards (pause, budget halt, secret-leak) gate the LLM call
(`pm.rs:316`) and the executor, but **not** the inline workspace ops — a
paused/exhausted cast will still provision worktrees and make git commits.

### MEDIUM — Two overlapping task-status models
`TaskStatus` (board: backlog/working/in_review/blocked/done) vs derived
`TaskState` (queued/working/in_review/awaiting_human/rejected/done) in
`graph.rs`. Overlapping but different vocabulary; different consumers pick one
arbitrarily (watchdog: TaskStatus, graph: TaskState). Deliberate but
undocumented mapping.

### MEDIUM — Docs debt (see §Cleanup)
`HANDOFF.md` 69KB graffiti-wall; `references/project-registry.md` for a deleted
feature; wrong CLI forms in `OWNERSHIP_BOUNDARY.md` / stale path in
`DEPLOYMENT.md`; `ADDENDUM.md`/`CASTING_PROJECT_BRIEF.md` need an
authoritative-vs-archival decision.

### MINOR — Reconciler vs Watchdog
Two "periodic inspect-and-maybe-emit" mechanisms: cursor-gated reconciler
(ReconcilePass) vs wall-clock watchdog. Split is correct (watchdog needs a
clock), but the distinction isn't framed in one doc.

## Recommendations

1. **Wire the executor into the side-effect path** (the headline fix). Route
   worktree provision/commit/prune as `Activity`s (or at minimum have the inline
   hooks consult the same `llm_dispatch_allowed` + secret-leak gate). This makes
   the guards reach the whole side-effect surface and removes the if-ladder.
2. **Document the TaskStatus↔TaskState mapping** (or collapse to one after the
   graph work proves out).
3. **Dedupe triage** classification into a single `triage.rs` call.
4. **Consolidate docs**: prune HANDOFF roadmap to current state; delete stale
   refs; fix CLI/path forms; make ADDENDUM/BRIEF explicitly archival or update.
